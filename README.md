# Real-Time Chat Platform

A full-stack real-time chat application built with **React, Express.js, Socket.IO, Prisma, and PostgreSQL**.

Real-Time Chat Platform lets users chat one-on-one or in groups with instant messaging, friend requests, status updates, and file sharing, all backed by Docker support for easy setup.


## Highlights

- JWT Authentication
- Real-Time Messaging with Socket.IO
- One-to-One & Group Chats
- Friend Requests & Blocking
- Status Updates(like stories)
- File & Image Attachments
- Typing Indicators & Read Receipts
- Online/Offline Presence
- Docker & Docker Compose

# Features

## Authentication

- User Signup
- User Login
- JWT Authentication
- Zod Validation
- Password Hashing(bcrypt)

## Chat

- One-to-One Conversations
- Group Conversations
- Send & Receive Messages in Real Time
- Message Reactions
- Delete Messages
- Typing Indicators
- Read Receipts
- Online/Offline Presence

## Attachments

- Upload Images & Files
- Store Attachments via AWS S3

## Groups

- Create Groups
- Join Groups via Invite Link
- Group Settings & Management

## Friends

- Send & Accept Friend Requests
- Remove Friends
- Block/Unblock Users

## Status

- Post Status Updates
- View Status of Friends
- Status View Tracking
